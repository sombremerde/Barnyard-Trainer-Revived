## 🚜 What Is Barnyard Save Architect?

Barnyard Save Architect is a desktop companion application designed to read, interpret, and gently reshape Barnyard save data. Where a traditional trainer might inject values into a running process, this tool works on the cold, still pages of your save file — the same way a restorer works on a painting rather than repainting it in the gallery.

The result is a workflow that feels less like cheating and more like **curation**. You decide which fields matter, which milestones you'd like to revisit, and which corners of your farm deserve a fresh coat of paint. Every modification is logged, reversible, and explained in plain language.

The project began as a personal curiosity: *"What does my save file actually remember about my farm?"* That curiosity grew into a full-featured suite with a blueprint editor, an inventory ledger, a milestone tracker, and a rollback system that keeps your original data pristine until you commit.

Barnyard Save Architect is built for tinkerers, archivists, speedrunners, and nostalgic players who want a second wind in a game they love — without losing the charm of the original journey.

## 📱 Responsive Interface & Design Language

The Barnyard Save Architect interface follows a philosophy we call **"quiet visibility."** Nothing shouts at you. Nothing flashes. Important information is always one glance away, but never in your face.

The layout is fully responsive across three breakpoints:

1. **Compact** — A single-column stacked layout for small windows and laptops, prioritizing the current task.
2. **Standard** — A two-panel layout with a navigation rail on the left and the working canvas on the right.
3. **Wide** — A three-panel layout that adds a live preview pane for diffs and statistics.

Every panel is resizable, every sidebar is collapsible, and every dialog can be dismissed with a single keystroke. The design respects users who prefer keyboards, users who prefer mice, and users who prefer both.

Accessibility is not an afterthought: color contrast ratios meet WCAG AA standards, all interactive elements are reachable via tab order, and screen reader labels are present on every control.

## 🧬 How the Save Blueprint Works

At the heart of the application is the **Blueprint** — a human-readable representation of your save file's structure. Rather than exposing raw bytes, the Blueprint exposes *concepts*: animals, buildings, inventory, currency, time, and progression flags.

When you load a save, the tool performs three steps:

1. **Parse** — The save file is decoded into a structured in-memory model.
2. **Validate** — The model is checked against a schema describing what a healthy save looks like.
3. **Present** — The model is rendered into the Blueprint editor, where each field is editable with context-aware controls.

When you save your changes, the process reverses with an added safety step: a snapshot is written first, then the new data is committed atomically. If anything fails mid-write, the snapshot is restored automatically.

## 🛡️ Safety, Backups, and Peace of Mind

Trust is earned through predictability. Every write operation in Barnyard Save Architect follows a strict protocol:

- **Snapshot before write** — No exceptions, no shortcuts.
- **Atomic commit** — Changes either apply fully or not at all.
- **Integrity validation** — Malformed data is rejected before it touches disk.
- **Manual backup shortcut** — One keystroke creates a portable backup archive.
- **Restore wizard** — A guided flow for rolling back to any prior snapshot.

If you ever feel uncertain, you can pause, review the diff, and cancel. Nothing happens without your explicit confirmation.

No. It's a companion. The game remains the experience; this tool is the workbench beside it.

No. The application works entirely offline.
